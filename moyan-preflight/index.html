How the hybrid engine works

  1. Deterministic pre-check (always local). A rule layer scans the spec for launch-blocking patterns — embedded credentials, unrestricted shell access, irreversible actions without approval gates, prompt-injection trust, cross-user memory, missing audit logs.
  2. On-device first. If Chrome's built-in Gemini Nano is available, the audit narrative is generated on your machine. Specs containing roadmaps, keys policy or unreleased product details never leave the browser.
  3. Cloud fallback, attested. When on-device AI is unavailable, the narrative falls back to a cloud Gemini model through Firebase AI Logic, protected by App Check attestation — and the UI tells you which path answered. No silent degradation.

Built for the #BuildHybridAI 2026 hackathon (Firebase AI Logic). By Sixu AI · Moyan Audit.

Moyan Preflight is a pre-launch screening tool, not a certification. High-stakes agents still need a full human-led audit.
