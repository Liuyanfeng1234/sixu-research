# sixu-research

**Sixu AI / V19 智能组织公开研究产出仓**

本仓是 V19 智能体安全审计项目（由 liu 与其智能体团队 Muse、小语、coco、Codex 组成的智能组织运营）的公开产出面：只存放已通过组织内部审核标准、可对外公开的研究材料。与之对应的开发仓为私有仓，不在本仓范围内；本仓不含任何私有仓代码、凭据或未审材料。

## 产出线

组织设「双产出」线（DEC-20261117-W036）：

- **答卷**：真实案例实跑审计报告（判定＋证据三级：已验证／未验证／未知）。实跑回执未出前不对外发布。
- **预测与覆盖报告**：以每日安全考卷库为底账的周期性报告——预测命中、事后覆盖、未覆盖三本账照实列示，方法与口径明示。

## 本仓内容

| 文件 | 内容 | 成熟度 |
|---|---|---|
| `exam-bank.md` | V19 安全考卷库公开版：24 条公开智能体/AI 安全事件逐条成账（事件与类别｜考题｜标准｜核验状态｜核验证据落点），每日更新 | 数据集 |

后续公开件（过审报告等）随组织审核流程逐件入仓。

## 成熟度标注口径（每件公开件必标）

- **数据集**：结构化原始记账材料，持续生长；字段与口径成文，但条数与统计深度有限，不构成统计结论。
- **工作报告**：方法与首批数据成文的阶段性报告（预印本形态），结论强度与数据量匹配、短板明示。
- **正式报告**：实跑数据与完整评分周期成账后、按目标刊物/会议格式成文的报告。

标注原则：够格上传、不够格自夸。成熟度只升不降级标注；发现错误走勘误公开更正、不删原文。

## 审核与发布纪律

- 公开渠道只收「官网级」件：须过组织五层审核标准（机器自检／作者自检／非作者复核／统筹终审／批准发布）＋全员合议门＋官网级加严门。
- 内部日常版产出永不外流至公开渠道。
- 预测类表述执行前瞻登记制：先登记（预测句／依据／可证伪条件／时间窗）、到期成账评分，禁止事后追认。

## 诚实口径

- 考卷库的覆盖核验是**规则覆盖级静态核验，不是端到端实跑**；V19 系统首次端到端 bring-up 仍在推进中，任何条目不得读作「实跑通过」。
- 「预测命中」指在册检查的引入时点早于事件公开日且证据齐备；引入晚于公开日的记「事后覆盖」；无在册检查的记「未覆盖」，照实列示。
